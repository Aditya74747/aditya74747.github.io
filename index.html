project 01, in detailscroll to run the agent

MCP Agent Database Open source

An AI agent that queries a database, searches company documents and manages files. Runs on a laptop with local models through Ollama, or on Claude or OpenAI with one setting.

the problem

An agent that can change a database and write files is useful, and a little dangerous. One bad query, or one instruction hidden inside a document, and it changes things nobody asked it to.

the plan

Three MCP servers behind one rule: only read-only tools run on their own. Everything else waits for a human. SQL is parsed, not pattern-matched. File paths can't leave the sandbox. Every decision goes into a JSONL audit log.

the proof

On a 14-task benchmark with local Qwen3 8B: 79% overall, 100% on safety and 0 unsafe actions run, at a median 6.8 seconds per task. One test document carries a prompt injection on purpose. 110 tests, a FastAPI web UI, a CLI and Docker.
